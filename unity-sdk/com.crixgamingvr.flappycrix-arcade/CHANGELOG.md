# Changelog

## 1.0.0
- First release: the Flappy Crix in-game version as an arcade cabinet for VR / Gorilla Tag fan games.
- Single player: attract mode, free play or coins, high scores with initials.
- Linked cabinets: races with nearby players (same seed, ghost birds, countdown), watching, IN USE, shared
  high scores, over PUN 2 / Fusion 2 / any transport, with no extra CCU.
- Procedural cabinet model with neon edges and drawn artwork; VR buttons, joystick, coin slot, touch screen.
